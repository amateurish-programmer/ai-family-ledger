# AI 家庭账本

面向 Android 的家庭记账 App，采用 Kotlin + Jetpack Compose + Room。当前版本 V1.7.0 在家庭云账本、在线更新与 AI 对话记账基础上，修复同步删除假冲突，并为云端 AI 格式异常增加服务端与本机双层兜底；已登录家庭注册后即可创建或加入家庭使用。

[GitHub 仓库](https://github.com/amateurish-programmer/ai-family-ledger) · [APK 构建与下载](https://github.com/amateurish-programmer/ai-family-ledger/actions/workflows/android-ci.yml)

## 当前版本 V1.7.0

- 修复本机与云端同时删除同一账目时被误报为冲突；删除与编辑同时发生时仍保留冲突保护。
- 云端 AI 返回格式异常时，明确的简单收支可自动整理为待确认记录；“今天意外收入1034元”会识别为 1034 元其他收入。
- 客户端输入限制为 2000 字；金额使用整数分，支持 0.01 至 999,999,999.99 元；AI 提案必须由用户确认后入账。
- 已通过后端协议、Android JVM/lint/编译、Android 模拟器和云端发布验证。

## 历史版本 V1.3.0 功能

- 温馨渐变自适应桌面图标；人情往来亲友收支排名、明细与历史 AI 确认整理。
- 账本页下拉刷新；同步状态在标题旁显示，完成后隐藏。启动每天静默检查一次版本，有新版才提示。
- 设置页手动检查更新，查看说明、下载进度与取消重试，校验安装包后调用系统覆盖安装；更新配置内置，无需登录 GitHub。
- 收入/支出新增、编辑、删除，关机重启后仍由 Room 保存。
- Excel 文件选择返回后排队执行导入/导出，导出全部未删除历史数据；新增消费按来源时分秒辅助区分疑似重复。
- 月/年报切换近六个月、近一年收支双折线，支持拖动、双指缩放及精确月度金额。
- 前台自动同步距最近成功不足五分钟时跳过，手动同步随时可用。
- 确认对话记账、编辑、删除、Excel 导入与撤销、人情历史整理和备份恢复后立即同步；此路径不受五分钟前台冷却和自动同步开关影响。
- 同步结果只显示非零数量，格式为“上传 2 条 / 下载 3 条 / 冲突 1 条”；没有变化时保持安静。网络失败不回滚本机提交，并明确提示本机已保存。
- 日期、两级分类、账户、归属成员、记账人、商家、项目、备注。
- 月度流水，日/周/月/年收支结余、前期比较、趋势与支出分类汇总。
- 对话和待确认提案保存在本机，退出登录或重启后保留；Room V4 非破坏性迁移。
- 邮箱验证码找回密码；家庭创建者修改家庭名称和图标，设置页修改本机角色与头像。
- JSON 备份、恢复预览、重复 ID 跳过与软删除标记保留。
- 随手记 XLSX 导入预览、逐行选择、疑似重复提示、来源追溯和批次撤销；三个工作表导出。
- 唯一文字对话入口，记账与提问自动识别；移除语音和独立“记一笔”。提案修改并确认后才入账。
- 基于家庭真实汇总的连续财务问答，解释消费结构、预算与储蓄安排；支持日期、成员、分类、关键词筛选。金额由 App 计算，模型引用原值。设置中编辑本机角色。
- 奶油白、暖橘与鼠尾草绿统一界面，家庭插画、聊天确认卡、日期分组流水和分层报告。
- 同步先比较版本，仅传输变化记录；批量上传/下载，进行中显示阶段，完成后只显示非零上传、下载和冲突数量。
- 报告增加成员支出、月度趋势、上期比较、文本导出与可选 AI 解读。
- 内置云端邮箱登录、家庭邀请、显式同步、冲突处理与打开 App 时同步；错误提示区分注册、发信和限流原因。
- GitHub Actions 测试、lint、Debug APK 构建与下载产物。

金额仅支持 CNY，以整数分保存。余额变更保留原值、不参与收支。数据库从 V0.1 非破坏性升级，JSON V2 可读取旧版备份。Supabase 与 DeepSeek 已部署，注册邮件投递和邮箱确认已有用户反馈及控制台记录；V0.9 家庭资料迁移和日周报告接口已部署，用户已保存验证码模板。测试与真机验收边界详见 [V1.7 说明](docs/V1.7.md)和[云端服务说明](docs/BACKEND_SETUP.md)。

## 不安装 Android Studio，获取 APK

仓库已配置云端构建。每次升级自动提交经检查的源码，并生成带版本号的安装包。打开上方 **APK 构建与下载**，选择成功运行，在 Artifacts 下载 `AI家庭账本-v1.7.0`，解压并安装 `AI家庭账本-v1.7.0.apk`。后续版本名称自动读取工程版本号，不生成本机 SHA-256 文件。也可 **Run workflow** 手动重建；`auth_checks` 在仅构建模式追加全部 JVM 测试，`device_tests` 启用模拟器测试。

已安装旧版的用户可直接在 App 设置页检查并升级至 V1.7.0；首次安装可下载最新 APK。发布需显式启用 `publish_release`，只有 JVM、模拟器及后端检查成功后才更新 Supabase 最新版本。

详细步骤见 [云端构建指南](docs/CLOUD_BUILD.md)。首次安装从空账本开始，不包含用户真实历史数据。

## 开发协作约定

- 本仓库由项目维护者直接开发，后续行为变更直接提交到 `main`，不再为常规开发创建功能分支或 PR。
- 每次版本升级必须同步更新本 README、对应 `docs/V版本.md`、版本号和发布说明；通过云端检查后再发布 APK。
- 远端只保留 `main` 主分支；历史发布内容以 Git 提交、版本文档和 GitHub Actions 记录为准。

## 工程结构

```text
android/                 Android 工程及 Gradle Wrapper
  app/src/main/          domain、Room、ViewModel 与 Compose 界面
  app/src/test/          金额、报表、备份 JVM 测试
  app/src/androidTest/   Room 持久化、恢复与 UI 测试
supabase/                家庭 RLS/RPC 迁移、AI Edge Function
.github/workflows/       云端 APK 构建与可选模拟器测试
docs/                    阶段设计、表格映射、构建与验收
scripts/                 本地辅助验证和源码打包
```

## 开发与验证

JDK 17 + Android SDK 35 环境下：

```sh
cd android
bash ./gradlew testDebugUnitTest lintDebug assembleDebug
# 有模拟器/设备时
bash ./gradlew connectedDebugAndroidTest
```

Gradle 8.11.1 使用官方 wrapper，并校验发行包 SHA-256。AGP 与 JDK/Gradle 的兼容依据见 [Android 官方说明](https://developer.android.com/build/releases/agp-8-9-0-release-notes)。

## 数据与后续阶段

原始 Excel、明文备份、数据库、模型密钥不得进入 Git。App 内置云端地址与公开客户端 key，模型密钥只配置在服务端。同步须主动确认上传范围；默认不开启自动同步。备份含私人账目，卸载前先导出备份。

V0.10 使用统一文字对话入口，设置页提供本机角色与头像。手机无需配置连接参数；首次使用对话前进入家庭账号与同步页面注册、登录并加入家庭。设备与云端检查边界见版本记录。

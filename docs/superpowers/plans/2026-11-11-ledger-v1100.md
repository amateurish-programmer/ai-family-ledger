# V1.10.0 实施与验收计划

用户已确认本聊天给出的分类与聊天分析方案，基于 V1.9.9 升级。

- [ ] 分类模板保留收支类型和两级关系，AI 接收完整分类树。账单编辑器支持选分类及手动新增，AI 提案继续编辑后确认。明确的旧分类进入预览，用户确认后事务修改并同步。
- [ ] 查询协议兼容旧客户端，增加多项包含和排除条件。私家车查询排除公共交通、购车和车贷，模糊旧账单列。筛选与金额使用本机完整有效账目，成员按归属筛选。
- [ ] 聊天分析以准确事实引用给出简短答案。查账结果可以展开明细与待核对账目。连续追问保存完整条件，模型失败保留计算结果。
- [ ] 报表分析通过记账聊天显示并继续追问，沿用报表当前期间。提交前确认待入账草稿，发送明细需要说明范围并确认。
- [ ] 用合成账目验证本人加油、家人代记停车、公交、家人加油、模糊交通费和重复命中。验证旧历史、手动编辑、确认入账、过期预览回滚、分类变更不影响金额与来源。
- [ ] 完成本机测试与构建、后端协议回归、模拟器测试及三主题小屏检查，部署兼容后端并验证真实模型调用。同步版本、README、版本记录与发布说明，签名提交 main，正式构建发布并交付同签名 APK。

实现分工使用 CategoryCatalog、ChatCodec 和 ConversationMemory 作为接口。分类与查询各自先做行为测试，主流程统一运行 Gradle。Room 保持 V4，历史分类修改复用现有账目同步通道。

# 网络诊断与脱敏导出实现计划

目标：荣耀手机无法在 Wi-Fi 或流量下发送对话时，不依赖连接电脑即可记录失败环节，主动检查固定服务入口，并由用户保存或分享脱敏诊断文件。

本轮用户请求新增功能，授权实现、按 AGENTS.md 在 main 提交、构建和交付。历史聊天布局改动已发布 V1.9.6；本次不恢复其余界面改版。未跟踪的历史诊断文档不纳入提交。

## 设计与约束

- 入口为设置 → 网络诊断，登录前也可使用。
- 用户先重现错误，再运行检查，保存或分享报告；不自动发送诊断文件。
- 报告包含 UTC 时间、机型、Android 与应用版本、网络能力及当前选路、两条固定入口的 DNS/HTTPS/HTTP 检查、最近最多二十条实际请求元信息。
- 实际请求记录跨进程保留；记录失败不得影响原请求结果、选路、鉴权或重试规则。
- 固定入口仅为现有 Pages 和原 Supabase；探测不带用户凭据，不调用模型、不新增流水、不切换手机网络、不放宽证书验证。
- 对话入口无授权探测的 HTTP 401 表示鉴权门槛可达，不证明已登录请求或模型响应正常；报告和界面明确该边界。
- 不记录请求或响应正文、聊天、账本、家庭或账户标识、令牌、邮件、IP、Wi-Fi 名称、设备唯一标识；仅保留白名单路径类别与异常分类。
- 所有网络与文件操作离开主线程；探测超时有界，可取消；同一页面不并发运行诊断。
- 分享使用独立 FileProvider，只授权缓存诊断子目录；保存使用系统文件选择器，不扩大更新包分享权限。
- 不变更 Room V4、云项目、包名和签名；版本升级为 1.9.7 / 29。

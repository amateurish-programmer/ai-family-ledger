# V0.9 持久化、账号与周期报告实施计划

目标：修复对话丢失，加入验证码找回密码、家庭和角色图标编辑、日周报告，并统一版本发布产物。

用户已授权持续升级及自动提交，沿用现有 Kotlin/Compose/Room/Supabase，不增加服务商或改变账本金额模型。

1. 对话：Room V2→V3 增加按绑定账号分区的消息和待确认提案表；退出不清除，重启加载；消息保存先于显示。提案确认与清空待确认状态在同一数据库事务中完成。验证迁移保留旧记录、重启保留对话、账号分区和确认幂等。
2. 身份：官方 recovery 验证码流程，恢复令牌只用于本次密码修改，不写入普通登录会话；保留 SMTP。家庭资料仅 owner 修改，同步给成员；本机角色和头像不是权限。提供行为测试与新增 SQL 迁移。
3. 报告：统一日/周/月/年边界，周一开始；金额整数分。更新报告 AI 数值校验接受已有日周日期，保留月年回归。
4. 界面：沿用 V0.8 温馨主题，提供固定图标选择、验证码重发状态及日周切换。
5. 发布：升级 0.9.0/code9，白名单签名提交，Actions 自动生成 AI家庭账本-v0.9.0.apk，不生成本机哈希文件。运行针对性 JVM/Room/UI 验证，部署服务端后交付，注明未实测范围。

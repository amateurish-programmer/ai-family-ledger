# AI 家庭账本 V0.1 Implementation Plan

> 执行方式：当前会话按 executing-plans 逐项完成。用户已要求按引用规划开始开发。

**Goal:** 交付可持久化的 Android 本地账本与云端 APK 构建配置。
**Architecture:** Compose → ViewModel → Repository → Room；domain 无 Android 依赖。后端依照原规划逐阶段接入。
**Tech Stack:** Kotlin 2.1.20、AGP 8.9.2、Gradle 8.11.1、JDK 17、Compose BOM 2025.04.01、Room 2.7.2。
**Spec:** ../specs/2026-09-05-ledger-v01-design.md

## Global Constraints

- minSdk 26；金额整数分；只支持 CNY；不混算余额调整。
- 不上传真实账本，不在移动端存模型密钥。
- 尚未运行的验证明确注明。

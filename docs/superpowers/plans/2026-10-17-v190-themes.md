# V1.9.0 四页改版与三主题实施计划

**Goal:** 按用户已确认的四页效果图实现三种可持久选择的主题，发布 v1.9.0 / versionCode 22。

**Architecture:** 在现有 Compose 主题之上增加本机外观偏好与样式令牌。四页共享真实账本与现有操作回调，主题不进入账目、权限或同步协议。页面采用紧凑标题、收支总览、分区报告和分层设置。

**Tech Stack:** Kotlin / Jetpack Compose / SharedPreferences / Room V4 / GitHub Actions。

**Spec:** 用户在本会话确认 `family-ledger-themes.html` 四页效果图，要求三个主题区分度高、默认奶油暖居、设置切换，并提交与发布。效果图为设计参考，示例数据不得进入生产界面。

## Global Constraints

- 原包名 `com.familyledger.app`、签名、Room V4 和家庭同步协议不变；金额继续使用整数分。
- 唯一文字记账入口、AI 提案确认、30 条聊天分页、滚动位置保留、同步时可输入等行为保留。
- 自动同步周期、自动上传、静默更新策略不改变。
- `main` 直接开发；明确文件清单提交；不包含已有未跟踪网络诊断文档、真实账本和凭据。
- 奶油暖居 `warm` 为缺省；手账生活风 `journal`、简洁财务风 `finance`，非法/旧偏好回退默认。
- 手账通过纸色、纸纹、便签描边、衬线金额与方形圆角区分；财务通过冷白、青灰、紧凑行距与无装饰数字排版区分；暖居使用暖橙、奶油底、家庭插画与较大圆角。
- 主题选择即时应用且重启保留，本机统一外观不随账号切换；改变主题不重建账本 ViewModel。
- 报表总览/分类/成员/人情共用当前日期周期，人情全历史模式保留；不得用效果图静态内容替代实际统计。
- 角色设置与历史账本同级，角色设置内包括名称、头像、家庭账号与同步；更新自动提醒仍能跳到更新操作。
- 发布须更新 README、Gradle、V1.9 文档、发布说明；交付 `AI家庭账本-v1.9.0.apk`，不生成本机 SHA-256 边车。

# V0.7 统一文字对话与本机角色

用户已授权持续开发与发布。本次直接实施三个明确要求，无需逐阶段等待验收。

目标：启动后进入文字对话，统一记账与账本问答；设置页提供按本机账号保存的角色。

- [x] 新增受约束 chat 协议：AI 提取待确认账目或查询条件，客户端按整数分计算实际统计。保留旧 parse/report 协议兼容旧版。
- [x] 对话页替换原一句话页面，移除语音和独立新增入口；账本列表仅保留已有记录编辑。回复和提案清楚区分已保存状态。
- [x] 保存本机账号角色，默认成员使用角色，记账人默认为发起角色；编辑角色不回写历史数据。
- [x] 更新版本至 0.7.0，部署函数、云端编译成功，记录验证边界；交付位置见 V0.7.md。

设计：四个导航项为对话、账本、报表、设置。聊天正文在上，输入框固定在下；用户消息与助手回复用轻量背景和留白区分，仅可操作提案使用卡片。发送时滚动至最新消息，等待状态反馈明确。输入、回复与草稿保留在当前进程，屏幕旋转不丢失，退出进程后不承诺保存聊天。

发送到模型的数据为输入、最近少量对话、日期、本机角色、账本中的成员/分类名称；不发送完整历史明细。问答只支持可表达为日期、成员、分类、关键词筛选的查询，复杂未支持请求应说明。计算结果基于本机副本，未同步数据不在结果中。新账目必须确认；整理历史账本只查询与汇总，不隐式修改或删除。

角色为业务归属标签，不是家庭管理员权限；按当前认证账号保存，未登录使用独立本机角色。默认“本人”，可自定义 1–20 字。确认前草稿保持原角色，避免设置变更改变待保存提案。

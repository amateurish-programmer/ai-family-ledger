# V0.2 Excel Implementation Plan

> 执行方式：本会话 inline，按 executing-plans 逐项实施并记录验证。用户已授权继续既定下一版本。

**Goal:** 交付支持随手记 XLSX 预览导入、查重、批次撤销和导出的 0.2.0 APK。
**Architecture:** XlsxCodec → SpreadsheetImport → Repository 事务 → ViewModel → Compose 预览；ImportOrigin 持久化到 Room V2，备份兼容 V1。
**Tech Stack:** 保持现有 Kotlin/Compose/Room；ZIP/SAX 标准 API，无新增办公解析依赖。
**Spec:** ../specs/2026-09-06-ledger-v02-design.md

## 约束

minSdk 26，CNY 整数分，真实工作簿不上传；5 MB 压缩/16 MB 解压/10,000 行/64 列。余额变更不计收支。旧数据库迁移不可丢数据。

# V0.3 至 V0.5 连续开发

用户在 V0.2 开发中要求“完成后继续进行后续阶段，无需验证”。因此连续实现原规划的后续功能，不逐版等待验收，不启动模拟器或专项验证；仅执行生成 APK 所需编译。阶段实现合并交付 0.5.0/code 5，不能将未部署云端描述为已在线。

## V0.3 一句话与语音

首页进入一句话记账；调用 Android 语音识别 Activity 获得文本，手机缺少服务时明确提示并保留键盘输入。简单整理在手机本地完成，明确展示默认日期/账户/成员；复杂语句可发送到已配置的服务端 AI。所有解析结果只是可编辑提案，用户确认后才事务写入。大模型输出限制 20 笔、严格金额字符串/日期/类型验证，禁止余额变更自动入账。输入长度最多 2000 字。

## V0.4 家庭云端

Supabase 邮箱账号、家庭创建/邀请、RLS 隔离、客户端显式同步。新增离线记录可一直保存在本机，首次同步前确认上传全部记录，包括历史导入来源与删除标记。移动端只存公开客户端键，令牌由 Android Keystore 加密；模型密钥仅服务端。

家庭绑定固定为当前账号/家庭，防止切换家庭时误传本机旧账本。服务端 revision 比较交换，本机记录是否修改用同步快照哈希判断。冲突保留并允许选择本机/云端，不静默覆盖；同步期间应用写操作使用同一忙锁。可选择打开 App 时同步；不承诺 App 关闭时实时后台同步。

云端 schema、Edge Function 与部署说明随源码交付。需要用户自己的 Supabase 项目和模型供应商配置，没有这些外部配置不能完成真实云端部署。APK 的离线功能不依赖配置。

## V0.5 报告

保留月报/年报分类总额，增加有效收支笔数、上期支出与差额、成员支出和近六个月/全年十二个月趋势。金额全部整数分计算，图表比例才转浮点。支持文本报告导出。AI 解读仅发送汇总数据，不发送逐笔备注；用户确认后调用服务端。报告结果关联当前期间和数据快照，切换期间或数据变化不展示旧解读。

# V1.2 人情往来与家庭图标

本版 versionName 1.2.0、versionCode 14，继续使用同一包名与签名，可覆盖升级。

## 图标与同步

桌面图标使用原生矢量的暖橙至奶油色渐变，房屋、爱心与打开的账本组合，提供独立背景/前景的 Android 自适应图标和应用内完整矢量。无新增图像依赖。

前台自动同步距上次成功不足 300 秒时跳过，恰好五分钟可触发。持久化时间、失败不更新时间、时钟回拨允许重试逻辑不变。手动同步、账本下拉刷新不受冷却限制；没有后台定时轮询。

## 人情报告

每笔记录新增 isGift 与 counterparty，分别表示已确认的人情标记和往来对象，与家庭成员、认证操作者分开。对话仍是唯一新增记账入口，AI 提案核对后保存；编辑页可以修改标记与对象。

报告沿用日/周/月/年范围，独立提供全部历史切换。收到、送出、差额和两个亲友排行榜均用整数分精确聚合。只纳入未删除人民币收入/支出，余额调整排除。对象只去首尾空格，不推断别名或合并亲友；金额降序，同额按名称稳定排序。未填写对象的有效人情记录计入合计，单列待补全，不参与排名。差额不是欠款，也不代表账户余额。

## 历史整理

分类选择来自本机有效历史收支，默认选中名称含人情、礼金、红包、送礼、收礼、随礼的分类，可以人工增减。分析按每批最多20笔向现有认证家庭AI接口提交ID、商家和备注，金额不交给模型修改。AI只提出对象建议，未识别对象保留空白；用户可逐条编辑、取消选择并确认。

确认使用 Room 原子事务比对原记录完整快照；有修改或删除时停止这次确认并要求重新分析。仅修改选中记录的人情字段和更新时间，不重复记账，不改金额、日期、原始导入来源。失败或取消分析不入账。

## 兼容与部署

Room 3 → 4 添加带默认值的人情字段，保留记录和对话，无破坏性重建。JSON备份版本2增加可选字段，旧备份缺失时取 false/空对象；Excel增加人情往来、往来对象两列。旧表格继续可导入，去重口径不因新增人情字段改变。

迁移 202609070001_gift_metadata 在原有受权限和CAS保护的云端写入上追加兼容触发器：旧客户端省略新字段时保留已有值，新版显式字段可以修改或清除；不改变金额或CAS修订规则。必须在发布新版前部署。同步指纹对默认人情字段沿用旧版规范，避免升级引起全量上传或误报冲突；真实人情修改与清除仍会改变指纹。AI新字段由 giftFields 显式请求启用，旧版客户端继续接收旧格式；人情历史整理采用独立的受认证接口操作。

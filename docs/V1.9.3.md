# V1.9.3 Wi-Fi 与移动网络分路

versionName **1.9.3** / versionCode **25**，保持包名、签名、Room V4、原 Supabase 项目身份和账号数据。

## 原因与处理

V1.9.2 的 Pages 入口已修复 Wi-Fi 原 Supabase 域名的连接重置，并通过 Wi-Fi 全量下载。但发布后移动网络下载新版出现探测进程中止；单独复验收到 200 及正确长度，120 秒内未完成。用同一手机、同一移动网络、同一个新版 APK 对照原 Supabase 地址，约 **4.60 秒**完整下载且摘要一致。此前新入口在移动网络下载旧版也曾通过，说明 Pages 移动网络路径存在不稳定现象，尚不能确定具体网络设备或运营商环节。

因此 V1.9.3 每次新请求按系统当前默认网络选择固定入口：Wi-Fi 使用 Pages；纯移动网络使用原 Supabase。网络未知或 VPN 等未明确为纯移动网络的情况使用 Pages。读取网络类型只使用 Android 普通网络状态权限，无需用户设置或授权弹窗。不修改 Wi-Fi、移动数据、DNS 或代理。

账号、密码恢复、家庭、同步、AI 和更新统一按此规则选择。两条路径均为固定 HTTPS 上游；存储的项目 URL、家庭归属、加密会话和同步索引不变。不会把入口选择当作换项目，不在执行中的写请求上切换或自动重试。更新清单和 APK 仍是同一发布物，安装前的长度、摘要、包名、版本和签名校验保持原规则。

## 升级

旧版首次可用原本可用的移动网络升级，或手动覆盖安装 `AI家庭账本-v1.9.3.apk`。不要卸载或清除数据。V1.9.2 若在移动网络下载缓慢，可切回可用 Wi-Fi 获取 V1.9.3，或手动覆盖修复。V1.9.3 安装后按实际网络自动选择入口。

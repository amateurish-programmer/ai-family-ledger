# V0.7.0 统一文字对话

首页为对话，只有一个文字输入框和发送按钮。移除语音、独立“记一笔”、简单整理与 AI 整理选择。其他导航为账本、报表、设置。原有账目仍可在账本中编辑、删除；文件导入保留在设置。

输入真实收支会生成可修改、移除的待确认卡片，确认才事务保存。待确认卡片处理完再继续发送，避免后续请求覆盖未保存草稿。普通问题显示回复，不入账；时间、成员、分类和关键词查询由 AI 提取条件，App 对本机有效人民币收支按整数分统计。问答注明查询范围与本机副本边界，排除已删除记录、余额调整和外币。历史账本“整理”当前为查询汇总，不会批量改删。复杂比较、预测等不在本版查询协议内，助手应明确说明。

设置提供 1–20 字本机角色，例如老公、老婆，按认证账号保存；未登录使用独立本机角色。角色为归属标签而非权限。新提案未明确成员时默认此角色，明确其他付款人时保留指定成员，记账人默认本机角色。修改角色不修改已有账目或已生成草稿。

对话需要联网、登录并加入家庭，失败保留输入供重试。发送内容包括当前输入、最近四条截断对话、日期、角色及至多四十个成员/分类名称；完整历史明细不发给模型，统计在本机完成。当前对话和未保存草稿保留在进程内，屏幕旋转保留，关闭进程后不保证恢复；已确认账目持久保存。退出账号清除当前聊天和未保存草稿。

后端增加 chat 操作，保留 parse/report 兼容已安装旧版；维持服务端 Auth、家庭成员检查和调用额度。模型与 SMTP 密钥不进入 APK。versionCode 7 / versionName 0.7.0，包名、开发签名和 Room schema 不变，可以覆盖安装。

检查计划：生成 APK 所需编译及角色归属、查询范围、金额精度的针对性检查；不启动模拟器或完整回归。实际模型语义效果和手机体验以安装后使用为准。

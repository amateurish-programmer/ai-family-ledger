# V0.10.0 导入导出修复、交互趋势与同步间隔

## 设计与故障链

用户反馈随手记增量导入显示零、导出 Excel 为 0B。源码发现系统文件选择器返回时 ON_START 可触发自动同步，随后 Activity Result 回调进入 perform 时遇到 busy 直接丢弃；CreateDocument 已创建的新文件因此没有写入。回归以合成账本和受阻 Room 写操作重现该竞争，不依赖生产账号。此证据不等同于用户手机日志；未获得用户本次最新工作簿。

另发现导入相似性只比较日期和业务字段，忽略来源时分秒。即使新增消费时间不同，同日同额同分类会被标为默认不选的疑似重复。修复预览与事务提交共用的时间判断；缺少准确时间仍保留疑似提示，只有同一文件内容和行位置生成的已有 ID 才为已处理。新导出不自动覆盖旧账。

范围：文件回调排队并等待本机加载；文件选择期间抑制前台自动同步；Excel 读取数据库全部未删除历史收支与余额调整，不受当前月份筛选；已有数量/大小限制仍显式报错。月/年报趋势新增六个月/一年双序列折线、平移缩放和精确值；日周明细趋势保留。前台自动同步距最近成功不足 60 秒时跳过，手动同步不受冷却限制，失败不更新时间戳。

官方参考：[Activity Result 的状态恢复](https://developer.android.com/training/basics/intents/result)、[ContentResolver 输出流](https://developer.android.com/reference/android/content/ContentResolver)。

独立复审补充：Excel 预生成不捕获旧页面 launcher，完成后发布待启动请求，由当前设置页一次性消费。生成期间切页/旋转不再向已注销 launcher 发起操作；对应请求保留与一次消费行为纳入模拟器检查。进程完全被系统终止前尚未完成的预生成不会持久化，需要重新导出。

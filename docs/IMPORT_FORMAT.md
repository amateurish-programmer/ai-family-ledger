## V0.2 导入契约

- 按表头定位，不把三种表格强行套用同一列下标。
- 日期支持 `YYYY-MM-DD`、`YYYY-MM-DD HH:mm:ss` 与 Excel 数字日期（1900/1904 日期系统）。时间原值存入 ImportOrigin，收支报表仍按来源日期统计，不擅自转换时区。
- 分类存在尾部空格，规范化字段需 trim，但原始行保留以便追溯。
- 归属成员与记账人独立，不能用成员字段推断认证身份。
- 金额转换为整数分，币种独立；不默默四舍五入超出两位小数的值。
- “余额变更”不能算作收入/支出；是否是目标余额或调整差额尚待核实，不能仅凭名称猜测。
- ImportOrigin 已保存账户2、项目分类、文件哈希批次、原始列值、工作表/行号和原始时间。Room V1→V2 新增来源列；编辑保留来源，JSON V2 完整备份保存来源。
- 单文件重复导入以文件内容哈希加原始行位置确保幂等；不同导出文件的同内容交易仅提示疑似重复，不默认删除真实的同额同日消费。
- 导入先预览：有效、新增、疑似重复、错误分别计数。确认后事务提交，可按批次回滚。
- 测试仓库只放合成夹具，不提交真实 XLSX。

## 使用边界

设置 → 导入随手记 Excel → 预览并勾选 → 确认导入。新增默认选中，疑似重复默认不选，错误及已处理行不可选。重复提示不是确定删除：同日同额真实消费可勾选保留。

设置 → 查看导入批次 → 撤销此批次，会软删除本批次当前记录，包括导入后编辑过的记录。删除标记保留，所以再次选择同一文件仍显示已处理。

仅未加密 `.xlsx`、CNY；文件 5 MB、解压 16 MB、10,000 数据行、64 列。公式行拒绝入账，错误原因在预览显示；未知工作表列在预览说明中。金额不四舍五入。余额变更允许零/负原值，不推断余额或调整差额。

导出 Excel 只导出当前未删除记录，保留两账户/项目分类/时间，金额是数值、其他内容以文本写入。Excel 不保存内部 UUID、删除标记和完整来源；换机完整迁移使用 JSON。未指定成员/记账人显示“未指定”，原始空字段仍在来源中保留。

# V1.1.0 账本刷新与启动更新提醒

版本1.1.0/code13。包名、固定签名、Room schema3与后端合同保持一致。

账本页在列表顶部下拉触发既有同步，空账本也可使用；不受自动同步成功后60秒冷却限制。加载、同步、其他操作或文件选择期间禁止重复下拉请求。同步结果通过现有Room数据流更新列表和汇总，失败保留原数据并显示现有错误提示。新增独立syncing状态，与通用busy一起清理；失败和取消也结束动画。

同步不再使用全宽顶部进度条或对话中的处理进度，改为当前页面标题旁旋转刷新图标与“正在同步…”，同步结束隐藏。导入、保存、AI处理等其他操作继续沿用其原有反馈，避免误标为同步。窄屏标题区域可以换行，图标文字保持可读。

启动/返回前台时尝试静默检查更新，以本机自然日记录日期，日期持久化后才请求；失败也计入当天额度，没有更新与网络错误不弹提示。发现新版本弹出说明，选择“查看更新”前往设置，或“稍后”关闭；不自动下载或安装。与设置页共用Activity作用域更新模型，下载/安装期间不覆盖更新状态。手动检查绕过日期额度，已有自动请求时等待它完成后执行新请求。提示在应用恢复前台且没有账本忙碌、加载、文件选择、编辑、导入等阻塞流程时展示。

更新下载、签名/散列核对、系统安装确认保持既有逻辑。本次新增行为测试覆盖刷新合并与防重、即时重试、失败/取消清理、空列表手势、忙碌/加载禁用，及日期持久化、跨日、失败静默、手动检查独立和更新模型状态保护。

依据[Android下拉刷新组件文档](https://developer.android.com/develop/ui/compose/components/pull-to-refresh)，使用Material3 pullToRefresh处理嵌套滚动；指示状态使用自定义标题组件。

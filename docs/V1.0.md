# V1.0.0 在线升级发布

用户要求升级到 v1.0.0，以便从已安装的 v0.11.0 体验在线更新。versionName为1.0.0，versionCode从11递增到12；版本发现与安装比较versionCode，因此可识别为新版本。此次提升版本与发布说明，功能沿用v0.11.0。

包名com.familyledger.app、固定开发签名和Room schema3保持一致。安装包名AI家庭账本-v1.0.0.apk；Storage对象为app-updates/releases/12/ai-family-ledger-v1.0.0.apk。正式版本名称不代表更换签名，不生成本机SHA-256边车文件。

沿用已部署更新流水线：明确文件清单签名提交，云端编译/JVM/模拟器/后端检查成功后串行发布APK，远端校验后再推进latest.json。完成后匿名下载并核对CI产物。本机没有Java，构建与设备检查由GitHub Actions执行；本次结果待下方补充。

操作：在v0.11.0打开“设置 → 应用更新 → 检查更新”，查看v1.0.0说明后下载，下载完成点击安装更新；如需安装来源权限，按引导授权，返回后再次点击安装更新，最后在系统界面确认覆盖安装。不要卸载旧版；升级后设置中应显示v1.0.0，原账本和对话应继续可见。真实手机在线升级由用户本次体验验收。

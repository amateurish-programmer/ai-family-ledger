# V1.9.4 记账页标题防覆盖

versionName **1.9.4** / versionCode **26**，保持包名、签名、Room V4、原 Supabase 项目身份和账号数据。

## 原因与处理

用户反馈记账页聊天内容偶尔覆盖顶部「家庭账本」标题，时有时无。检查 QuickEntryScreen 布局：外层 Column 依次绘制标题行、分割线、聊天 LazyColumn（weight 1f 占满中段）和输入区。Compose 同一父级内后绘制的子项画在先绘制的子项之上；聊天列表自身不裁剪越界绘制的内容，标题行原先也没有独立背景与显示层级，因此滚过列表顶边的聊天内容会画到标题上。是否可见取决于滚动位置、animateContentSize 动画中间帧与字体缩放，表现为偶发。

报表页在 V1.9.0 修复过同构问题：固定控件加 `zIndex(1f)` 与不透明背景（提交 73890c4）。V1.9.4 对记账页采用同一方案：标题行与分割线包进固定上层 Column，`zIndex(1f)` 加主题背景色，滚动的聊天内容不再画在标题上。不改变布局尺寸、对话分页、提案确认与输入逻辑。

## 升级

旧版在设置页检查更新，或手动覆盖安装 `AI家庭账本-v1.9.4.apk`；不要卸载或清除数据。账号、家庭、账本、主题选择和安装签名保持不变，覆盖安装保留全部数据。

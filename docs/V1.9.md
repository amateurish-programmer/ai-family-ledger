# V1.9.0 四页改版与三种主题

versionName 1.9.0 / versionCode 22，基于 main 的 V1.8.0（e127899）。沿用包名、安装签名、Room V4 与云端接口。

## 外观与使用

- 默认「奶油暖居」：暖橙、奶油底色、圆润面板与家庭插画。
- 「手账生活风」：纸张底色、横线纸纹、便签装饰、小圆角和衬线金额。
- 「简洁财务风」：冷白、青灰、紧凑行距与纯图标。主题差异包含排版和装饰。
- 在「设置 → 外观主题」即时切换。本机保存选择，重启保留；未知偏好回退奶油暖居。外观不随账号退出删除，也不上传家庭成员。
- 记账：唯一文字入口；助手回复支持基础标题、粗体和列表排版；待确认流水采用小票样式。入账确认和三十条分批加载规则保留。
- 账本：紧凑收支摘要、日期分组、对齐金额；点击记录从底部展开明细，保留编辑与二次确认删除。下拉刷新和标题旁同步状态保留。
- 报表：总览、分类、成员、人情四个分区，共用日、周、月、年期间。总览优先呈现趋势和 AI 入口，人情继续支持全部历史、待补全与亲友明细。
- 设置：家庭摘要，下设角色设置、历史账本、备份与恢复、外观主题、应用更新。角色页包含名称、头像及家庭账号与同步。
- 四个标签与设置子页保留状态；更新提醒仍能直接进入应用更新页面。

金额继续按整数分计算；主题和文字排版不会更改账目。图表浮点仅用于绘制比例。AI 不计算报告合计。真实账本、备份、凭据和效果图示例数据不进入生产界面。

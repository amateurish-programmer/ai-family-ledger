# V0.11.0 应用内更新

设置页新增“应用更新”，显示本机实际版本，手动检查最新版本、更新说明与大小，用户点击后下载。下载有进度、取消和重试；下载完成核对文件大小、SHA-256、APK 包名、versionCode/versionName、minSdk 和签名兼容性。安装按钮每次重新校验，借助仅共享 updates 缓存目录的 FileProvider 调用 Android 系统安装界面。无安装来源权限时解释并引导，返回后由用户再次点击安装。

更新使用独立 ViewModel，页面切换和旋转保留进行中的状态。安装请求由当前设置页面一次性消费，不捕获旧 Activity 的 launcher。取消时等待下载清理完成才允许重试。账本忙碌、初始加载或文件选择时禁用安装，避免主动中断数据处理。进程完全退出后可以重新检查与下载；不提供永久后台下载或静默安装。

更新地址内置，未登录也可检查。Supabase 独立公开读取桶 app-updates 保存 latest.json 与 releases/版本号/APK，最大50 MiB，只允许 APK/JSON 类型。服务端发布凭据保存于 GitHub Secrets，不进入 App。工作流显式 publish_release=true 且主分支 JVM、模拟器及后端检查成功后，串行上传不可覆盖的版本包、远端核对文件，最后推进最新版本。检查失败不会发布；旧版本无法覆盖更新的 latest。详见 [客户端合同](UPDATES_CLIENT.md)和[发布维护](UPDATES_PUBLISH.md)。

不改变 Room schema3、包名 com.familyledger.app、既有固定开发签名、家庭同步和模型服务。版本为0.11.0/code11；沿用签名仅为覆盖安装兼容，不因 APK 正式文件名而改变为独立正式签名。不要卸载旧版后安装。

## 部署与验收记录

已创建 app-updates 桶并读回公开属性、MIME 限制与50 MiB限制；已通过官方 Supabase CLI 取得服务端发布凭据并通过标准输入保存 GitHub Actions secret。凭据没有输出、写入源码或本机文件。尚待本版云端编译、模拟器检查和发布后匿名下载结果补充。

合成覆盖：清单严格解析、版本比较、下载流损坏/截断/取消，真实签名 APK 的同签名通过和异签名拒绝、FileProvider 范围、ViewModel 取消与重试/安装请求一次消费/校验失败不启动安装，Compose 更新说明/进度/忙碌禁用安装，以及发布幂等、防降版、上传失败、去敏和清单合同。

用户需先手动覆盖安装本版一次，后续通过“设置 → 应用更新 → 检查更新”更新。真实手机的安装来源授权及最终系统覆盖安装仍需设备端验收；模拟器校验不等同于所有手机厂商安装界面。测试 APK 是临时生成的最小归档，不发布、不安装、不含账本。

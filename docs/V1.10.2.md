# V1.10.2 切回 Wi-Fi 后的下拉刷新

版本号 1.10.2，版本代码 34，最低 Android API 26。安装包为 `AI家庭账本-v1.10.2.apk`。

## 旧版表现

2026 年 11 月 18 日，同一台 vivo V2430A 的 V1.10.1 在 10:04:27 和 10:04:52 两次经 Wi-Fi 访问 Pages，读取家庭资料时等待 HTTP 响应头失败。两次均未收到状态码。之后经蜂窝线路读取家庭资料和清单成功。

受控测试中，切回 Wi-Fi 后下拉可以正常完成。另一次在下拉请求在途时短暂断开 Wi-Fi，家庭资料读取 89 毫秒后以 I/O 错误结束，恢复 Wi-Fi 后这次刷新随即终止。Android 的默认网络在切换期间可能改变，应用此前会直接上报这次连接错误。

## 恢复范围

遇到连接中止、重置或意外流结束时，应用等待系统默认网络连续两次采样为同一个已验证网络，再依照当前网络选路。采样间隔 400 毫秒，最多等八个间隔。只对该次读取额外尝试一次。

允许恢复的操作为读取家庭资料、同步清单的一页、账目详情和共享头像。账目上传、家庭资料修改、AI、登录、令牌刷新及找回邮件沿用原有处理。账户权限响应和证书验证失败会直接交回各自的处理流程。同步连接持续中断时，界面提示网络稳定后重新下拉。

## 行为验证

249 项本地 JVM 测试全部通过，跳过数为零。应用及设备测试 APK 构建成功，lint 错误为零。回归覆盖网络切换、离线等待上限、取消、读写区分、已知 HTTP 错误正文截断，以及同一读取同时遇到连接中断和令牌过期。一次令牌续期不会增加网络补试次数。

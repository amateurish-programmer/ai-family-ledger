# V1.9.5 报表收入来源与分类明细

versionName **1.9.5** / versionCode **27**，保持包名、签名、Room V4、原 Supabase 项目身份和账号数据。

## 原因与处理

用户需求：报表的日/周/月/年报告中增加收入来源分类；支出去向与收入来源都能点击进入二级分类，查看该分类本期花费明细（如点「01.养娃」查看养娃明细）。

处理方式：

- 领域层 `LedgerReport` 新增 `incomeSources`（本期收入按一级分类汇总，与支出分类同构：整数分累加、按金额降序）。`text()` 导出在支出分类后同步输出收入来源。
- 报表分类页在「支出去向」下方新增「收入来源」区块：沿用排行卡片样式，收入侧使用鼠尾草绿（与收入金额配色一致），进度条占比分母为本期收入。
- 两个区块的分类卡片均可点击，进入明细底部弹层（与人情往来明细同构）：显示分类名、期间、合计金额与笔数，以及该分类本期逐笔记录（日期、类型、金额、一级/二级分类、成员、账户、备注）。明细仅读取本机已保存账目，过滤规则与报告一致（排除已删除、非人民币和余额调整）。
- 不改变总览、成员、人情区块，不改变记账、编辑、同步与更新逻辑。

## 升级

旧版在设置页检查更新，或手动覆盖安装 `AI家庭账本-v1.9.5.apk`；不要卸载或清除数据。账号、家庭、账本、主题选择和安装签名保持不变，覆盖安装保留全部数据。

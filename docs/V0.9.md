# V0.9.0 · 对话保存、账号资料与日周报告

## 功能

- 对话与待确认提案写入 Room V3，按本机绑定账号分区，退出不清除，重新打开应用加载。确认提案与清空待确认状态为同一事务；重复确认不重复入账。消息不再截断为最后八十条，发给模型的上下文仍有限。对话保存在本机，不自动同步到家人设备或放入账本 JSON 备份；未发送输入框文本暂不跨进程保存。
- Room 2→3 只新增对话表，不重建账目。旧版没有保存到数据库、已经消失的对话不能恢复。
- 忘记密码：发送邮箱验证码，输入验证码与两次新密码，通过独立 recovery 会话更新；不写入恢复令牌或替换本机绑定账号。成功返回登录；验证码失效、发送失败、弱密码和更新结果不确定有明确提示。详见 [身份说明](IDENTITY_V0.9.md)。
- 家庭名称和图标由家庭创建者修改，成员刷新或同步后可见；角色名称和头像在设置页编辑并按本机账号保存，不充当权限。家庭图标与角色头像为内置选择。
- 新增日报、周报；周一开始，跨月跨年正确；保留月/年报、前期比较、趋势、导出和 AI 解读。详见 [报告说明](REPORTS_V0.9.md)。
- 每次升级自动提交受检源码并构建。APK 与源码包从 Gradle versionName 自动命名，交付 `AI家庭账本-v0.9.0.apk`，不生成本机 SHA-256 文件。沿用原包名和安装签名以便覆盖更新；文件名称不改变签名类型。

# V0.8 家庭账本界面设计

## 设计与实现

视觉方向：奶油白纸感底色、暖橘操作色、鼠尾草绿财务辅助色，以舒适留白、清晰数字层级和家庭矢量插画建立统一视觉。所有插画均为本地 Canvas 图形，无网络图片、客户数据或额外资源依赖。

内容结构：对话作为唯一新记录入口；账本围绕月份、收支结余和日期分组明细；报告围绕总览、分类、成员、趋势和解读；设置按角色、家庭账号、历史账本、备份恢复分组。卡片只用于财务总览、消息与待确认记录等需要独立识别的内容，常规设置使用列表和分隔线。

交互方向：月份标题淡入切换，聊天消息与待确认内容尺寸过渡，登录提示展开收起；保留 Material 点击与导航反馈。对话可滚动，输入器固定在内容底部，处理键盘与 Scaffold inset；操作按钮保持舒适触控尺寸。装饰图标不重复朗读，发送按钮提供“发送”无障碍描述，处理状态和表单错误使用 live region。

## 页面变化

- 主题统一定义颜色、字号、行高、字重和圆角。主操作暖橘，收入与家庭总览用鼠尾草绿。
- 对话首页加入本地家庭插画、简短说明和两条可编辑示例问句；点击示例仅填入输入框，不自动发送。消息区显示角色和助手身份；用户消息与助手回复有不同方向和表面层次，支持复制文字。保留一个文字输入器。
- 待确认记录突出金额，展示日期、分类、成员、账户及记账人，保留修改、移除和全部确认保存。未确认内容仍阻止发送下一轮，不自动入账。
- 账本按日期降序分组，记录行用类型/分类图标辅助扫描；金额完整保留，归属、账户和备注使用次级层级。月份选择、编辑与两步删除操作保留。长详情支持滚动。
- 报告保留本地整数分统计结果，突出本期结余及与上期差额。分类与趋势图使用明确的收入/支出颜色和文字数值；比例浮点只用于画图。保留成员统计、导出和 AI 解读确认。
- 设置页展示本机记录数，角色可编辑与保存；家庭账号、Excel 导入导出、批次撤销和完整备份采用说明清楚的列表。版本显示 V0.8.0。
- 家庭页区分账号、创建或加入家庭、同步开关、邀请码与冲突处理。同步仍保留原确认流程。
- 编辑页突出金额，并将必填账目详情与选填补充信息分组，保留原有校验、来源信息及放弃编辑确认。

## 接口与数据边界

不修改 Room、金额解析、统计、导入、备份或同步权限逻辑。所有现有页面函数接口和模型方法保留；新增读取 `LedgerState.operationStatus`，由 ViewModel 提供实际处理阶段。角色仍是归属标签，不是家庭权限。

聊天短说明显示“AI 处理本轮文字与收支汇总；分析基于本机账本”。AI 数据范围、服务端调用和财务分析协议由 V0.8 对应业务设计说明，界面不计算模型报告总额。

## 验证边界

本 UI 子任务完成源码检查：确认页面回调、金额格式化和确认入口保留；新增浮点只用于 Canvas 坐标和报告图表比例；新增共享组件无外部资源；无语音和独立新增记录入口。

本机无可用 JDK，未在本 UI 子任务运行 Gradle、Android 模拟器、截图或 TalkBack。编译与自动化测试由主任务统一执行并记录结果。设备验收仍需检查 360dp 窄屏、系统大字体、软键盘、长消息、多笔待确认、长金额、日期切换、角色保存、导入及同步冲突流程。本说明不代表设备视觉验收通过。

现有 UI 测试需按新语义定位发送图标 `contentDescription=发送`、输入占位“记收支，聊聊家庭财务…”和字段标签“角色名称”。

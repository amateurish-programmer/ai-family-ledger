# V1.8.0 AI 与长对话体验

versionName 1.8.0 / versionCode 21，基于远端 main 的 V1.7.0（65dce34），沿用原包名、签名和 Room V4。旧工作目录差异已保存在本机忽略目录中的快照，发布后统一主工作目录。

## 行为变化

- 只有可明确证明的本人简单已发生交易允许本机/服务端规则回退。第三方归属、人情语义、否定、未来和假设不能被回退抹除。账户缺失标“未指定”；所有新增仍需确认。
- 新版最多四组受控查询，支持期间、成员、分类、关键词、收支方向及人情对象。程序执行筛选与整数分合计，提供分类/成员/商家排名、有限明细及组间差额；模型只解释证据。
- 回复证据保留原始事实标签和值，禁止模型自行填金额与比例。分析失败展示程序计算的结果，不冒充分析成功。
- 既有 ChatMessage.context 保存查询条件，最近八条上下文和最多八项较早用户陈述提供给 AI。只在当前账号消息内提取，用户陈述不等于核实的财产或已入账交易。
- 分析/报告默认启用 DeepSeek 思考；可单独配置分析模型。请求预算有界，不发送原始全量账本，不改变模型密钥位置、家庭鉴权或配额。
- 页面首次显示最近三十条，向上到顶部点“继续加载”再增加三十条。更早记录仍持久化，加载和切页保留位置；同步状态变化不滚动；本人发送或处于底部时才跟随新消息。

本次不修改同步协议、数据库结构或升级安装签名；不迁移国内后端。已有公共网络 connection reset/timeout 的历史限制仍适用，模型能力改进不代表网络路径已修复。

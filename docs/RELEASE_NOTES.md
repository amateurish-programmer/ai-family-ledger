# V1.0.0 在线升级发布

发布 v1.0.0（versionCode12），供已安装 v0.11.0 的用户在设置页检查更新并覆盖安装。沿用既有包名、签名与数据库，保留家庭账本和对话数据。此次仅提升发布版本及更新说明，功能与 v0.11.0 一致。构建与发布记录见 [V1.0](V1.0.md)。

## V0.11.0 应用内更新

新增“设置 → 应用更新”：手动检查、查看更新说明和大小、下载进度与取消重试，文件和签名校验通过后调用系统覆盖安装。更新配置内置，安装权限由系统授权，升级保留本机数据。云端仅发布通过全部必要检查的安装包，首次需手动安装本版。沿用包名、签名及数据库，详见 [V0.11](V0.11.md)。

## V0.10.0 文件操作修复与交互趋势

修复文件选择器返回后自动同步抢先占用导致导入/导出丢失、Excel 留下 0B 的问题；生成表格后再选保存位置，导出全部未删除历史收支与余额变更。同日同额但准确发生时间不同的导入记录可以识别为新增，疑似重复仍需手动确认。月/年报新增六个月/一年双收支折线，可平移、缩放和查看准确金额。前台自动同步增加成功后一分钟冷却，手动同步不受影响。沿用数据库、包名和签名，详见 [V0.10](V0.10.md)。

## V0.9.0 对话保存、验证码找回与日周报告

对话与待确认记录保存在本机，退出和重启不清除；新增邮箱验证码找回密码、家庭名称和图标编辑、本机角色头像、日报与周报。确认入账和回复保存为同一事务。升级自动提交仓库，安装包命名为 `AI家庭账本-v0.9.0.apk`，不输出本机 SHA-256 文件。沿用包名与签名，可覆盖更新。部署和验证见 [V0.9 记录](V0.9.md)。

## V0.8.0 家庭财务助手与温馨界面

对话接入程序计算的家庭财务摘要和连续上下文，支持财务结构分析及条件性预算/储蓄建议；同步改为版本清单与变化批处理；统一主要页面视觉。保留包名、签名及本机账本，可覆盖安装。详见 [V0.8 记录](V0.8.md)。

## V0.7.0 文字对话与本机角色

统一文字聊天入口，移除语音及独立新增按钮；支持收支提案、账本查询与普通回复。设置页可编辑按账号保存的本机角色。现有数据、包名和签名保留，详见 [V0.7 说明](V0.7.md)。

## V0.6.0 家庭账号升级

内置云服务公开配置，移除用户端地址/key 输入；保留原有账号、家庭、同步索引与本机账本。增加可操作的注册、邮件和限流错误提示。versionCode 6，可覆盖 V0.5，包名/签名和 Room schema 不变。APK 编译与七项针对性检查通过，详见 [V0.6 记录](V0.6.md)。

## V0.5.0 历史功能

由 V0.1 连续完成原规划 V0.2 至 V0.5 的源码功能，统一版本号 0.5.0。按用户要求跳过本轮功能验证，云端构建只编译 APK。

## 手机端

- 历史账本：设置中导入随手记 `.xlsx`，查看有效/错误/已处理/疑似重复记录，选择后入账；同文件重复导入幂等。保留导入时间、工作表、行号和原始字段，支持批次撤销与 Excel 导出。
- 一句话：简单文本在本地整理；语音按钮调用手机识别服务；复杂文本可选云端 AI。返回提案可修改/移除，用户确认后才保存。
- 报告：月报/年报、分类支出、成员支出、上期比较、月度趋势、文本报告导出。AI 解读只接收汇总，不接收逐笔备注。
- 家庭：配置自己的 Supabase 公开地址/客户端键后，邮箱注册/登录、创建或邀请加入家庭、主动同步、显式处理冲突，可选打开 App 时同步。

## 数据升级

保持原包名与开发签名，versionCode 从 1 升至 5。Room 数据库 V1→V2 增加来源列，不删除原表；JSON V2 保存来源并支持读取 V1 备份。不要为了更新卸载旧版；更新前可在设置中导出完整备份。

Excel 仅做表格交换，不包含 UUID 和删除标记；完整迁移使用 JSON。余额变更保留带符号的原金额，不推断账户余额，也不计收支。

## 云端启用

代码、当前部署状态与手机连接信息见 [BACKEND_SETUP.md](BACKEND_SETUP.md)。2026-09-06 后续已部署 Supabase 迁移和 AI 函数，配置 DeepSeek 与 QQ 邮箱 SMTP，用户已保存服务端密钥和邮件授权码。未进行手机、邮件投递与真实模型请求验收。离线记账、表格、简单整理和确定性报告不依赖这些配置。

登录其他家庭不自动切换本机账本；绑定后更换家庭需先备份并使用独立应用数据。同步会共享本机全部账目与导入来源，应将同一家庭的账目放在该实例中。后台关闭 App 时不承诺实时同步。

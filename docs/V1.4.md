# V1.4.0 记账输入与家庭角色设置

本版 versionName 1.4.0、versionCode 16，沿用原包名、签名和 Room 数据库，可覆盖升级。

## 记账输入

底部导航的“对话”标签改为“记账”，内部路由和对话历史保持不变。同步家庭账本时，输入框继续可编辑并保留草稿；只有发送按钮禁用，避免同步几秒钟时无法输入。发送请求仍由独立的 `chatSending` 状态防止重复提交，其他编辑、导入和恢复操作继续锁定输入。

## 家庭角色设置

设置页把角色名称、角色头像、家庭账号与同步放进同一个“我在家里的角色”区域，与“历史账本”同级。家庭账号入口仍打开原有家庭页面，登录、创建/加入家庭、家庭名称和图标、手动同步、自动同步、邀请码及冲突处理能力不变。

## 验证范围

新增 JVM 策略测试覆盖同步期间输入可编辑、发送期间输入锁定、空闲状态可发送及其他操作忙碌时锁定。更新 Android UI 测试使用“记账”标签和新的家庭角色设置入口。云端 CI 需执行 JVM、lint、APK 编译、协议回归和隔离数据库检查；真实手机键盘输入、弱网同步时长和覆盖安装属于真机验收。

交付包名为 `AI家庭账本-v1.4.0.apk`，不生成本机 SHA-256 边车文件。

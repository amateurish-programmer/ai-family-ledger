# V1.10.0 分类与聊天分析

基于 V1.9.9，versionName 1.10.0、versionCode 32。使用现有包名和签名，Room V4。

## 分类

记账提案使用有父子关系的收支分类树。私家车费用与公共出行分开，家庭已保存的自定义分类可复用。编辑记录时选择一级分类后清空二级，二级仅显示当前一级的选项。可手动新增分类。AI 提案的金额、日期、成员、备注继续编辑并确认后保存。

设置 → 历史账本 → 整理历史分类，展示确定的原分类与新分类对照，可以取消勾选，并在最终确认后统一保存。金额、账目 ID、日期、归属、来源、人情标记保持原值。确认期间账目已变化或删除则拒绝过期修改。旧分类不会在打开应用时自动改写，模糊交通费留待核对。

新草稿可参考同商家至少两笔一致的历史分类习惯。建议仍出现在待确认提案中。

## 聊天查询与分析

查询支持多个包含分类、关键词及排除项，继承连续追问中的完整条件。“我今年养车花了多少，不含公共交通”按照当前角色的账目归属统计。油费、车辆充电、停车、通行、车险和维修保养可计入，公交、地铁、网约车、购车和车贷排除。用途不明的交通记录列为待核对。

查询结果的金额、笔数和比较由程序使用整数分计算，模型选择已有事实解释。新协议允许模型在短句中引用精确事实，服务端验证后填入原值。默认简短回答，明确要求明细或解释时再展开。模型暂不可用时仍显示程序统计。

聊天中的查询结果可点击查看当前完整明细和待核对记录。后续账目变化时明细按当前账目重算。报表总览及成员、分类明细支持进入聊天分析，并携带当前期间与筛选。报告确认弹窗说明发送范围，整期分析最多发送四十笔明细节选。

# V1.6.1 云端开发与部署流程验证

本版 versionName 1.6.1、versionCode 19，沿用原包名、Room 数据库和安装签名，可覆盖升级 V1.6.0。

## 变更范围

本版仅升级版本元数据和发布说明，不改变记账、同步、报告、AI、导入导出或更新逻辑，也不包含数据库迁移。目的是验证从仓库提交到 GitHub Actions 全量检查、版本化 APK 构建，再到 Supabase 应用内更新发布的完整云端流程。

## 验证计划

先执行发布脚本的本地合成 Storage 回归和静态差异检查。随后在 `main` 分支手动运行 **Android APK** 工作流并启用 `publish_release`；该模式强制执行 JVM 测试、后端协议与 PostgreSQL 权限测试、Android 35 模拟器测试、APK 构建和发布。只有所有前置任务成功才允许更新 Supabase 的 `latest.json`。

交付包名为 `AI家庭账本-v1.6.1.apk`，不生成本机 SHA-256 边车文件。云端运行、公开清单和 APK 的实际结果将在流程结束后补充；流程成功前不声明已经发布。

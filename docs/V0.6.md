# V0.6.0 家庭账号升级

- App 内置现有 Supabase 项目地址和公开客户端 key。家庭页面只保留注册、登录、家庭邀请与同步，不再要求用户部署或填写云配置。
- DeepSeek API Key、SMTP 授权码和 service_role 均不进入 App。
- 旧版使用同一云项目时自动接续公开配置，保留加密账号、家庭绑定和同步索引。若检测到其他项目的身份或同步索引则停止云操作，避免跨家庭传输；离线账本仍可使用。
- 注册错误区分验证邮件发送失败、邮箱未验证、密码错误、邮箱无效和限流；未知响应显示 HTTP 状态，不向用户输出服务端原始内容。
- 包名与开发签名保持不变，versionCode 6 / versionName 0.6.0，可直接覆盖 V0.5，Room schema 未变。

本轮构建与检查状态见 VALIDATION.md。云端日志已观察到手机访问 `/auth/v1/signup` 返回 HTTP 500，底层原因排查中，不能把更清楚的错误提示等同于服务端故障已修复。

# V0.6.0 家庭账号升级

- App 内置现有 Supabase 项目地址和公开客户端 key。家庭页面只保留注册、登录、家庭邀请与同步，不再要求用户部署或填写云配置。
- DeepSeek API Key、SMTP 授权码和 service_role 均不进入 App。
- 旧版使用同一云项目时自动接续公开配置，保留加密账号、家庭绑定和同步索引。若检测到其他项目的身份或同步索引则停止云操作，避免跨家庭传输；离线账本仍可使用。
- 注册错误区分验证邮件发送失败、邮箱未验证、密码错误、邮箱无效和限流；未知响应显示 HTTP 状态，不向用户输出服务端原始内容。
- 包名与开发签名保持不变，versionCode 6 / versionName 0.6.0，可直接覆盖 V0.5，Room schema 未变。

构建运行 https://github.com/amateurish-programmer/ai-family-ledger/actions/runs/34004326878 成功，七项针对性测试通过。APK 为 `dist/apk/app-debug-v0.6.0.apk`，可以覆盖安装，无需卸载或重新配置云服务。

## 注册失败原因与处理

2026-09-06 09:22 的手机 `/auth/v1/signup` 请求返回 HTTP 500。对应 Auth 日志显示 QQ SMTP 返回 `535 Login fail`，发生在注册验证邮件发送阶段。进一步核对设置发现 SMTP Username 被错误地拼接成两遍发件邮箱地址，这是此前自动填写造成的配置错误。

已将 Username 修正为单个发件邮箱地址，保留原有 SMTP 授权码。保存后重新载入设置页，确认正确用户名持久保存，保存按钮禁用（无待保存更改）。没有读取授权码、创建测试用户或主动发送测试邮件；实际注册及邮箱投递需用户重试确认。客户端错误提示改进和 SMTP 配置修正是两项独立修改。

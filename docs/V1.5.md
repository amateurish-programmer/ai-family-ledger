# V1.5.0 前台自动检查更新

## 更新检查

应用每次进入前台时调用现有公开 `latest.json` 清单检查版本。检查保持静默：无新版时不显示“已是最新版本”，网络或清单错误也不弹错误；检查过程不会自动下载或安装。发现高于当前版本的清单后，只有在账本加载、同步、编辑、导入导出等阻塞状态结束且界面恢复到前台时，才弹出“发现新版本”对话框。选择“查看更新”进入设置页沿用原有下载、校验和系统安装流程，选择“稍后”可关闭本次提示。

每次进入前台都允许新的自动检查，并用 ViewModel 的活动任务和已有更新状态防止同一前台事件重复请求或覆盖正在下载、校验、安装的状态。设置页手动检查继续绕过自动检查限制。

# V1.6.0 删除同步冲突修复

本版 versionName 1.6.0、versionCode 18，沿用原包名、Room 数据库和安装签名，可覆盖升级。

## 修复范围

账目删除使用软删除标记继续参与家庭同步。此前当远端删除记录的同步版本发生变化，而本机缺少该账目的同步索引时，合并器会把“本机未编辑的旧账目”和“远端删除标记”当作普通内容冲突。现在比较本机 `updatedAt` 与远端 `deletedAt`：远端删除时间更新时直接接收远端墓碑并提交索引；本机在远端删除之后有编辑时仍保留冲突，不覆盖本机内容。

金额、账目 ID、CAS 版本和云端权限协议不变；删除仍不会物理移除记录，备份和后续同步可保留墓碑。

## 验证

新增同步合并回归测试覆盖：无同步索引时远端较新删除自动落地；本机较新编辑与远端删除仍产生冲突。保留既有双向软删除、CAS 冲突、索引提交失败和远端版本回退测试。本机 Gradle 受 Android SDK 组件和中文路径限制无法完成；云端流水线执行 JVM、lint、APK、模拟器、后端和发布检查。真实双手机删除时序仍需真机验收。

交付包名为 `AI家庭账本-v1.6.0.apk`，不生成本机 SHA-256 边车文件。

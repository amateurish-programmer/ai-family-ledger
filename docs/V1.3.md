# V1.3 账本变更即时同步

本版 versionName 1.3.0、versionCode 15，继续使用同一包名、Room V4 数据库和安装签名，可覆盖升级。

## 变更后同步

已登录并加入家庭时，下列本机事务提交成功后立即执行一次完整增量同步：确认文字对话生成的记账提案、编辑已有记录、删除记录、确认 Excel 导入、撤销导入批次、确认人情历史整理、确认 JSON 备份恢复。一次确认包含多笔记录时仍只发起一次同步。

这条变更后同步路径不检查设置中的自动同步开关，也不受前台五分钟冷却限制。五分钟限制仍只用于打开 App 或回到前台时避免重复同步；下拉刷新和手动同步继续随时执行。本版没有增加后台常驻服务或定时轮询，App 被系统停止后不承诺实时同步。

本机事务是数据落盘边界，网络同步在其后执行。网络失败时保留已提交的本机数据，提示“已保存在本机，自动同步失败：原因”；后续变更、手动刷新或符合条件的前台同步会再次上传。未登录或尚未加入家庭时只保存本机并显示原操作结果，登录并加入家庭后可用现有同步上传。

所有变更和同步仍经过 ViewModel 的同一互斥锁串行执行。编辑页可在本机保存完成后关闭，同一操作的同步图标持续到网络结束；重复点击不会并行发起多次同步。

## 同步结果提示

同步成功后只按固定顺序显示非零项：上传、下载、冲突，例如“上传 2 条 / 下载 3 条 / 冲突 1 条”。某项为零时省略，三项均为零时不显示提示。进行中的标题刷新图标和阶段文字保留，原来的耗时、请求次数及“同步完成”长提示不再面向用户展示。

冲突不会被自动覆盖，仍进入既有冲突列表由用户选择。本次只修改提示与触发时机，不修改整数分金额、云端 CAS 合并、批量协议、家庭权限或人情字段兼容规则。
